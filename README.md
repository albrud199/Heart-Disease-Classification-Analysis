# Heart Disease Classification Analysis

> A reproducible, leakage-aware, research-grade machine learning pipeline for heart disease classification using structured clinical data.

This project implements an end-to-end Machine Learning pipeline designed for rigorous tabular data classification. The goal is to provide a single authoritative production pipeline that includes robust validation, exploratory data analysis (EDA), advanced modeling (baseline through hybrid ensembles), probability calibration, explainability, and a deployment-ready inference handoff.

## 🚀 Key Highlights

- **Research Emphasis**: Leakage prevention, robust nested cross-validation, ensemble evaluation, probability calibration, and explainability (SHAP).
- **Engineering Emphasis**: Reproducibility, deterministic execution, structured pipeline, versioned artifacts, and deployment-ready inference.
- **Problem Type**: Binary tabular classification predicting the presence of heart disease from clinical features.

## 📂 Project Structure

The project is structured into sequential phases, ensuring a logical flow from data ingestion to production. The core codebase is located in the `Heart-Disease-Classification-Analysis/` directory.

### Core Pipeline Phases
1. **`phase1_foundation.py`**: Data provenance, EDA, leakage audit, and train/val/test splits.
2. **`phase2_modeling_foundation.py`**: Preprocessing architecture, feature engineering, feature selection, and baseline modeling.
3. **`phase3_advanced.py`**: Class imbalance handling, hyperparameter optimization, and advanced model training (KNN, SVM, Random Forest).
4. **`phase4_ensemble_ablation.py`**: Hybrid ensemble construction and comprehensive ablation studies to verify complementarity.
5. **`phase5_calibration_final_eval.py`**: Probability calibration, decision-threshold analysis, and final evaluation on the locked, untouched test set.
6. **`phase6_explainability_robustness.py`**: Explainability (SHAP), error analysis (false positives/negatives), robustness, and subgroup analysis.
7. **`phase7_production_handoff.py`**: Packaging the final pipeline (preprocessing + model + threshold) into a serialized artifact for production.

### Other Components
- **`production_inference.py`**: Standalone script for running inference using the serialized production artifact.
- **`models/`**: Directory for saving trained model artifacts, serialized pipelines, and evaluation metrics.
- **`splits/`**: Stores generated train, validation, and locked test datasets (CSVs) to ensure reproducibility.
- **`eda/`**: Generated charts, correlation matrices, and distribution visualizations from exploratory data analysis.

## ⚙️ Setup and Installation

1. Clone the repository and navigate to the project root:
   ```bash
   git clone <your-repository-url>
   cd Heart-Disease
   ```

2. Create and activate a virtual environment (recommended):
   ```bash
   python -m venv .venv
   # On Windows:
   .venv\Scripts\activate
   # On macOS/Linux:
   source .venv/bin/activate
   ```

3. Install the required dependencies:
   ```bash
   pip install -r requirements.txt
   ```

## 📊 Dataset

The primary dataset used is `heart.csv`, which contains structured clinical features (e.g., age, sex, chest pain type, resting blood pressure, cholesterol levels) used to predict the likelihood of heart disease. 
- Ensure `heart.csv` is placed in the expected data directory before running the pipeline.

## 💻 Usage

To train the models and generate the final production artifact, run the phases sequentially from the `Heart-Disease-Classification-Analysis` directory. 

*Note: Do not jump directly to the final phase. Each phase builds upon the artifacts and validation splits generated by the previous one.*

```bash
cd Heart-Disease-Classification-Analysis
python phase1_foundation.py
python phase2_modeling_foundation.py
python phase3_advanced.py
python phase4_ensemble_ablation.py
python phase5_calibration_final_eval.py
python phase6_explainability_robustness.py
python phase7_production_handoff.py
```

To run inference on new data using the final serialized model:
```bash
python production_inference.py --input new_patient_data.csv
```

## 🔬 Methodology & Roadmap

This project adheres to a strict [ML Engineering Research Roadmap](./Heart_Disease_Kaggle_ML_Engineering_Research_Roadmap.md) to ensure integrity:
- **No Data Leakage**: Operations that learn from data (imputation, scaling, feature selection, SMOTE) are strictly fit only on training folds. The test set is conceptually locked until the very end.
- **No Test-Set Tuning**: Hyperparameter tuning, feature selection, threshold selection, and ensemble weighting rely solely on training/validation evidence.
- **More Than Just Accuracy**: Models are evaluated on multiple metrics including Discrimination (ROC-AUC, PR-AUC), Sensitivity/Recall, Specificity, Precision, and Calibration (Brier score).
